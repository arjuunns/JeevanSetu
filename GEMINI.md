# Repository Guidelines for JeevanSetu

## Diagrams and Flowcharts

- All diagrams, flowcharts, architecture overviews, and visual workflows must be created using **Excalidraw** (via `excalidraw-skill`, Excalidraw MCP tools, or `npx -y mcp-excalidraw-server`).
- Persist diagram source files as `.excalidraw` or `.excalidraw.md` under `docs/` or corresponding module docs.
- The live canvas can be viewed at `http://127.0.0.1:3000`.
