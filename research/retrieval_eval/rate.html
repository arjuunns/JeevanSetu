Retrieval rating

How to rate

For each passage, judge how useful it is for deciding this patient's ESI triage level. 2 = directly useful (a criterion that applies to this patient: a high-risk presentation, danger-zone vitals, a life-saving intervention, a resource rule). 1 = somewhat useful (related background). 0 = not useful. Ratings save in this browser as you go. When every passage is rated, click "Download ratings" and move the file to research/retrieval_eval/ratings.json.
